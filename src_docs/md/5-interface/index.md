# Part 5. Translating the interface

This part follows a single interface string from the catalog to the screen. It explains how to keep the compression of a compact English label, how not to add or drop detail, which parts of a label belong to the translator and which to engineering, how plurals and placeholders behave in real Qt catalogs, how the voices of labels, tooltips, help and store copy differ, what to do when the English is wrong, what German, Spanish, French and Polish each demand, and how to review the result in the running application. The worked examples come from the FontLab 9 localization of 2026.
