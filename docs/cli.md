# Command-line reference

Generated by `scripts/gen_cli_docs.py` from `localizzy … --help`; do not edit by
hand. Fire accepts `--flag value`, `--flag=value` and, for booleans,
`--noflag`. List flags take comma-separated values.

## localizzy

```text
NAME
    localizzy

SYNOPSIS
    localizzy GROUP | COMMAND

GROUPS
    GROUP is one of the following:

     tm

COMMANDS
    COMMAND is one of the following:

     translate
       Translate CATALOG into --target using memories, then an optional engine.

     upgrade
       Port APPROVED translations onto FRESH lupdate output; write NEW and RETIRED.

     convert
       Convert catalogs; use source_format=i18next for application JSON.

     qa
       Run the deterministic content checks on a catalog; exit 1 on blocking findings.

     review
       Serve configured catalogs with the optional review UI and API.

     inventory
       Inventory all .tmx and .ts XML catalogs recursively under ROOT.
```

## localizzy translate

```text
NAME
    localizzy translate - Translate CATALOG into --target using memories, then an optional engine.

SYNOPSIS
    localizzy translate CATALOG TARGET <flags>

DESCRIPTION
    Lists are comma-separated: --direct-memory a.tmx,b.tmx. Direct memory hits
    (id > context > source) and whole-string glossary terms fill messages before
    the engine; --finish-on picks which classes are written finished. A catalog
    already in the target language keeps its complete translations; turn that
    off with --nokeep-existing (or --keep-existing=False), which needs an engine
    and an --out other than CATALOG. --out may be omitted
    only for a TS catalog that keeps its language. The report JSON goes to
    --report (default OUT.localizzy.json); --provenance=extra also writes
    <extra-localizzy-origin> into TS messages.

POSITIONAL ARGUMENTS
    CATALOG
        Type: str
    TARGET
        Type: str

FLAGS
    -o, --out=OUT
        Type: Optional[str | None]
        Default: None
    -r, --report=REPORT
        Type: Optional[str | None]
        Default: None
    -d, --direct_memory=DIRECT_MEMORY
        Type: Optional[str | None]
        Default: None
    --glossary_memory=GLOSSARY_MEMORY
        Type: Optional[str | None]
        Default: None
    --memory_lang=MEMORY_LANG
        Type: Optional[str | None]
        Default: None
    --glossary_status=GLOSSARY_STATUS
        Type: str
        Default: 'approved,do-not-translate'
    --finish_on=FINISH_ON
        Type: str
        Default: 'id,context,term'
    --memory_only=MEMORY_ONLY
        Type: bool
        Default: False
    --plural_count=PLURAL_COUNT
        Type: Optional[int | None]
        Default: None
    -k, --keep_existing=KEEP_EXISTING
        Type: bool
        Default: True
    --provenance=PROVENANCE
        Type: str
        Default: 'sidecar'
    -e, --endpoint=ENDPOINT
        Type: Optional[str | None]
        Default: None
    --model=MODEL
        Type: Optional[str | None]
        Default: None
    --fallback_models=FALLBACK_MODELS
        Type: Optional[str | None]
        Default: None
    -a, --api_key_env=API_KEY_ENV
        Type: str
        Default: 'OPENAI_API_KEY'
    -c, --cache=CACHE
        Type: Optional[str | None]
        Default: None
    --temperature=TEMPERATURE
        Type: float

    -s, --style_file=STYLE_FILE
        Type: Optional[str | None]
```

## localizzy tm

```text
NAME
    localizzy tm

SYNOPSIS
    localizzy tm COMMAND

COMMANDS
    COMMAND is one of the following:

     build_ui
       Build a project memory (every finished message) from a Qt .ts catalog.

     ts2tmx
       Convert one .ts file or every .ts under a folder to TMX (legacy language policy).

     po2tmx
       Convert one .po file or every .po under a folder to TMX (legacy language policy).

     lproj2tmx
       Convert an .app bundle's .lproj/.strings and .loctable files into per-language TMX.

     adobe2tmx
       Convert an Adobe app folder's localization resources into per-language TMX.

     oss2tmx
       Fetch upstream translations of open-source apps and write <app>/<lang>.tmx.

     norm
       Rename every .tmx under a folder to its shortest BCP 47 tag (legacy tmxnorm).

     extract
       Extract selected TMX pairs from bilingual, paired or multilingual resources.
```

## localizzy tm build_ui

## localizzy tm extract

```text
NAME
    localizzy tm extract - Extract selected TMX pairs from bilingual, paired or multilingual resources.

SYNOPSIS
    localizzy tm extract INPUT OUTPUT <flags>

DESCRIPTION
    TS/PO uses legacy eligible first/last plural projections. Languages come from
    metadata or explicit arguments, never guessed filenames. Source and target
    resource files join by key; loctables select two internal tables. Return every
    unmatched target key. Invalid text/XML preserves the existing output.

POSITIONAL ARGUMENTS
    INPUT
        Type: str
    OUTPUT
        Type: str

FLAGS
    --source=SOURCE
        Type: Optional[str | None]
        Default: None
    --source_lang=SOURCE_LANG
        Type: Optional[str | None]
        Default: None
    --target_lang=TARGET_LANG
        Type: Optional[str | None]
        Default: None
    --source_format=SOURCE_FORMAT
        Type: Optional[str | None]
        Default: None
    -f, --fuzzy=FUZZY
        Type: bool
        Default: False
    -d, --dedupe=DEDUPE
        Type: bool
        Default: True
    -v, --verbose=VERBOSE
        Type: bool
        Default: False
    --source_key=SOURCE_KEY
        Type: Optional[str | None]
        Default: None
    --target_key=TARGET_KEY
        Type: Optional[str | None]
        Default: None

NOTES
    You can also use flags syntax for POSITIONAL ARGUMENTS
```
